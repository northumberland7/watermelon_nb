# 西瓜数据集 3.0 朴素贝叶斯分类

## 数据集

本项目唯一使用的数据集是**西瓜数据集 3.0**，共 17 个样本、8 个特征。

- 样本数：17
- 特征数：8（6 个离散特征 + 2 个连续特征）
- 类别：好瓜 8 个、坏瓜 9 个
- 缺失值：无

**主模型只使用「密度」和「含糖率」两个连续特征。**

原因是 sklearn 的 GaussianNB 要求输入为数值特征，6 个离散特征（色泽、根蒂、
敲声、纹理、脐部、触感）必须先编码成数字才能使用，而编码后的整数并不服从
正态分布。离散特征的处理方式在第 9 节单独讨论。

## 运行方式

1. 安装依赖：`pip install -r requirements.txt`
2. 运行主程序：双击 `run.bat`，或在项目文件夹里执行 `python main.py`

## 可复现性

数据划分、交叉验证均固定 `random_state=42`，在 `main.py` 顶部以常量
`RANDOM_STATE` 统一定义，各步骤一律引用该常量。

## 目录说明

- `main.py`：主程序
- `figures/`：程序生成的图片
- `watermelon3.0_source.csv`：数据集
- `requirements.txt`：依赖清单
- `run.bat`：一键运行脚本
